# Genova VR

Genova VR is a generative AI framework for transforming educational prompts into editable virtual reality experiences. Its workflow connects planning, scene composition, external object modeling, narration, quizzes, selective revision, and publication for VR playback.

## Manuscript Status

**Peer review pending.** The manuscript has been submitted to IEEE Access and has not been accepted.

**Title:** Genova VR: A Generative AI Framework for Transforming Prompts into Complete Educational Virtual Reality Experiences

**Authors:** Jonathan da Silva Santos and Jean Pierre Raulin, Universidade Presbiteriana Mackenzie, Brazil.

The engineering case study examines solar-system formation, blood circulation, and mechanical-clock operation. It evaluates generated artifacts and documented playback observations, not learning effectiveness. The full manuscript is not included in this repository.

## Code and Data Availability

Upon article acceptance, the complete original source code and essential resources needed to reproduce the study and corroborate the reported results will be released here. These include experience descriptions, case inventories, screenshots, memory observations, hardware metadata, and reproduction scripts and instructions.

Before acceptance, code, data, and essential reproducibility materials will also be provided to IEEE Access editors upon request through the corresponding author. These materials are not publicly released here yet.
